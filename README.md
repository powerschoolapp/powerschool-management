# Power School Management System

A modern full-stack school management system built with Java, Spring Boot, MySQL, HTML, CSS, and JavaScript.

## Project

Power School Management System V2 is a redesigned and improved version of the original school management application.

The project focuses on:

- Modern responsive user interface
- Secure authentication
- Role-based authorization
- REST APIs
- Database-driven school management
- Clean frontend and backend architecture
- Production-ready deployment
- AI-assisted development

## Technology Stack

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Java 21
- Spring Boot 3.5
- Spring Security
- JWT
- REST API
- JPA / Hibernate
- Maven

### Database
- MySQL
- Aiven Cloud

### Deployment
- GitHub
- Render
- Aiven

## User Roles

- ADMIN
- TEACHER
- STUDENT

## Current Features

- Secure login
- BCrypt password hashing
- JWT authentication
- Role-based authorization
- Protected backend APIs
- Responsive login interface
- School branding and logo
- Separate role-based dashboard structure
